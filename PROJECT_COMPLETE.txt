📈 API ENDPOINTS (20+ Total)

AUTHENTICATION
   POST   /api/auth/register
   POST   /api/auth/login
   GET    /api/auth/me

USERS (Admin only)
   GET    /api/users
   GET    /api/users/:id
   PUT    /api/users/:id
   DELETE /api/users/:id

CLASSES
   POST   /api/classes
   GET    /api/classes
   GET    /api/classes/:id
   POST   /api/classes/:id/enroll
   POST   /api/classes/:id/remove-student
   DELETE /api/classes/:id

TASKS
   POST   /api/tasks
   GET    /api/tasks/class/:classId
   GET    /api/tasks/:id
   DELETE /api/tasks/:id

SUBMISSIONS
   POST   /api/submissions
   GET    /api/submissions/task/:taskId
   GET    /api/submissions/student
   POST   /api/submissions/:id/grade
